# 🧮 Calculadora Web

Uma calculadora simples e funcional desenvolvida utilizando **HTML**, **CSS** e **JavaScript**, com foco em praticar manipulação do DOM e lógica de programação no front-end.

## 🚀 Funcionalidades

* Operações básicas: adição, subtração, multiplicação e divisão
* Interface intuitiva e responsiva
* Atualização dinâmica dos valores na tela
* Validação de entradas

## 🛠️ Tecnologias utilizadas

* **HTML5** → Estrutura da aplicação
* **CSS3** → Estilização e layout
* **JavaScript** → Lógica e interatividade


## 🎯 Objetivo

Este projeto foi desenvolvido com o objetivo de fortalecer conhecimentos em desenvolvimento web, principalmente na manipulação de eventos e elementos do DOM com JavaScript.
